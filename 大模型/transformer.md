### 大模型transformer原理
1. 输入序列 → 输入处理模块 → 编码器堆 → 解码器堆 → 输出处理模块 → 输出序列
      1.0. 输入处理模块： 包括：词嵌入 + 位置编码(为了理解顺序)。
      1.1. 编码器堆：负责 “理解输入语义”（如翻译时理解源语言、问答时理解问题），
      1.2. 解码器堆：负责 “生成目标输出”（如翻译时生成目标语言、对话时生成回复）；
      1.3. 核心共性：编码器 / 解码器均由「N 个相同的 Transformer Block（隐藏层）」堆叠而成（原始论文 N=6）。
                1.3.1. 隐藏层结构： 归一化层 → 注意力（Attention） → 残差连接 → 归一化层 → 前馈网络（Feed-Forward） → 残差连接
                1.3.2. 归一化层：目的是标准统一，最大值都是1.
                1.3.3. 注意力层：进行语义关联捕捉（核心加工）
                           1.3.3.1. 注意力机制的核心目标：解决信息筛选与关联问题： 长距离依赖 + 信息冗余(多余的介词副词等)
                           1.3.3.2. 注意力机制的三大关键类型： 自注意力(句子前后关联) + 掩码注意力(输出时只关注已经生成的，忽略未生成的) + 跨注意力(翻译时的一一对应生成)
                           1.3.3.3. 注意力计算方式： 
                                           1.3.3.3.1. Q(查找)K(键特征)V(内容)矩阵，三者是注意力机制的核心载体。
                                           1.3.3.3.2. 通过计算 “查询（Query）” 与 “键（Key）” 的相关性，给 “值（Value）” 分配权重，最终加权求和得到 “聚焦关键信息的输出”
                1.3.4. 残差连接：层的 “输入” 直接加到 “输出” 上，让梯度能轻松穿越深层网络，避免 “梯度消失”，“打通层与层之间的信息通道”。
                1.3.5. 前馈网络：强化单个词的语义表达
      1.4. 输出处理模块: 包括： 线性层(将向量映射到词表维度) + softmax层(将词表维度的数值转化为概率分布，取最高分)
      1.5. 标准 Transformer 是双堆结构，但实际大模型会根据任务裁剪，核心组件保留核心逻辑：
               1.5.1. 编码器 - only 模型（如 BERT、RoBERTa）：只保留编码器堆，用于 “语义理解任务”（如分类、命名实体识别、问答匹配），核心依赖自注意力的双向语义捕捉；
               1.5.2. 解码器 - only 模型（如 GPT、LLaMA、Qwen）：只保留解码器堆，用于 “生成任务”（如对话、文本创作），核心依赖掩码自注意力的顺序生成；
               1.5.3. 编码器 - 解码器模型（如 T5、BART）：保留双堆结构，用于 “序列转换任务”（如机器翻译、文本摘要、数据清洗），核心依赖跨注意力的语义对齐。



### 微调 (PEFT parameter effecient fine tunning)
1. loRA (low-rank adaption) 低秩适配
         1.1. 核心是不修改大模型的全部参数，只训练极少量新增的 “小参数”，从而适配特定任务（比如翻译、问答、总结）。
         1.2. 核心假设：大模型的参数矩阵是 “高秩” 的，但任务适配只需要 “低秩” 信息
                  大模型的核心层（比如 Transformer 的 Attention 层）有一个超大的权重矩阵W （比如 1024×1024），
                  LoRA 认为：针对特定任务，只需要给W 加一个 “微小的低秩矩阵” 就能适配任务，不用改 W 本身
         1.3.  LoRA 的操作方式： 
                  1.3.1. 冻结大模型的所有原始参数（不更新）；
                  1.3.2. 为核心层（比如 Attention 的 q/k/v 矩阵）新增两个极小的低秩矩阵 A （1024×8）和 B （8×1024），总参数仅约 1024×8+8×1024=16384 个（对比原矩阵 1048576 个，仅占 1.5%）；
                  1.3.3. 训练时只更新A和B，原始权重完全不动；
                  1.3.4. 推理时，把 A×B 的结果加到原矩阵 W 上，相当于 “给原模型打了个小补丁”。
         1.4. 可以一次训练一个 LoRA（一套 A/B 低秩矩阵）适配电商 + 教育两个领域，也可以训练两个独立 LoRA 分别适配 —— 核心取决于领域数据的 “兼容性” 与业务的 “灵活性需求”，两种方案各有取舍。
2. 指令微调（Instruction Tuning，常称 SFT）
        2.1. 是在预训练模型基础上，用 “自然语言指令 + 对应输入 + 输出” 的标注数据做监督微调，把 “只会预测下一个词” 的基础模型，升级为能理解用户指令、生成符合要求结果的实用模型。
        2.2. 提升泛化性：通过多任务指令数据，让模型能零样本 / 少样本处理未见过的任务（举一反三能力）；
        2.3. 本质是有监督微调的一个子集，可分全参数指令微调（更新所有参数，效果好但成本高）和参数高效指令微调（如结合 LoRA，只更少量参数，成本低）。
3. 人类反馈强化学习（RLHF）：
          通过人类评分训练奖励模型，用 PPO 算法优化，让输出更符合人类价值观、更安全、更连贯。
